# To-Do List Web Application

This is a simple and interactive To-Do List web application built using HTML, CSS, and JavaScript for managing daily tasks efficiently.

## Live Demo
https://pitamghosh.github.io/synent-task5-todo-pitam/

## Project Objective
The objective of this project is to build a task management application where users can add, complete, delete, and filter tasks.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks (All / Completed / Pending)
- Data persistence using localStorage
- Responsive design

## Development Process
1. Created the basic structure using HTML  
2. Designed the interface using CSS  
3. Added functionality using JavaScript  
4. Implemented localStorage for saving tasks  
5. Added filtering options
